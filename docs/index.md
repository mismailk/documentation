# Documentation Site

Welcome! This is the documentation site for **this project** — a VitePress 1.6 docs site where **the `docs/` directory is the single source of truth for the sidebar**. There is no hand-maintained navigation configuration: adding, renaming, or removing a Markdown file automatically updates the sidebar on the next build.

Everything you need to use, extend, and deploy this site lives in the sidebar:

- [Getting Started](/getting-started/) — how the site works and how to author pages
- [How to Contribute](/contributing/) — the documentation's own contribution guide
- [Reference](/reference/commands) — commands and deployment

The sidebar you are reading right now was generated from the filesystem. Add a page and it appears here on the next `npm run docs:build`.
