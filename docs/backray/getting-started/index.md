# Getting started

Five steps take you from nothing to a running dashboard in your Express app.

1. [Get the packages](1-get-the-packages.md): build them once from the Backray repository.
2. [Install them in your project](2-install.md): one `npm install` command.
3. [Add the dashboard](3-add-the-dashboard.md): the one line, and how to try it.
4. [Read the problems it reports](4-read-the-problems.md): the console report, the Health page, and what to do.
5. [Run it in production](5-run-in-production.md): access, shutdown, updating.

Then change what the dashboard shows with the [features](../features/index.md).
