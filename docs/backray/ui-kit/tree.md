# Tree

A collapsible tree of nodes. In edit mode, each row's menu adds, moves, duplicates and removes nodes, rows can be dragged, and every action works from the keyboard. All its labels are passed in, so it speaks the page's language.

```tsx
import { Tree } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-tree--docs" target="_blank">open it in Storybook</a> and use the toolbar.
