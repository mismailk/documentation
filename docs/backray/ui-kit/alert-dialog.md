# Alert dialog

A dialog that interrupts to confirm an action, such as deleting a record. It has to be answered: Cancel or the action.

```tsx
import {
  AlertDialog,
  AlertDialogTrigger,
  AlertDialogContent,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogCancel,
  AlertDialogAction,
} from "@backray/ui";
```
