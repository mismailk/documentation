# Sheet

A panel that slides in from the side of the screen, such as the dashboard's phone menu. Pass `closeLabel` to translate its close button.

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetFooter,
  SheetClose,
} from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-sheet--docs" target="_blank">open it in Storybook</a> and use the toolbar.
