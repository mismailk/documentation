# Combobox

A searchable list to pick one value from, including values loaded as you type.

```tsx
import { Combobox } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-combobox--docs" target="_blank">open it in Storybook</a> and use the toolbar.
