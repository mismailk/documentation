# Toaster

Short messages that appear for a moment, such as "Saved". Mount `Toaster` once and call `toast()` anywhere.

```tsx
import { Toaster, toast } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-toaster--docs" target="_blank">open it in Storybook</a> and use the toolbar.
