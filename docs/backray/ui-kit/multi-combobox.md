# Multi combobox

A searchable list to pick several values from; the picked values show as chips.

```tsx
import { MultiCombobox } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-multicombobox--docs" target="_blank">open it in Storybook</a> and use the toolbar.
