# Button

The action button, in the `primary`, `secondary`, `destructive`, `outline`, `ghost` and `link` variants and the `xs` to `lg` and icon sizes. `buttonVariants` styles a link as a button.

```tsx
import { Button, buttonVariants } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-button--docs" target="_blank">open it in Storybook</a> and use the toolbar.
