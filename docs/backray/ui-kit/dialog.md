# Dialog

A window over the page for a short task. Pass `closeLabel` to translate its close button.

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
  DialogClose,
} from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-dialog--docs" target="_blank">open it in Storybook</a> and use the toolbar.
