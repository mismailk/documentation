# Select

A button that opens a list to pick one value from.

```tsx

  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectLabel,
  SelectSeparator,
} from "@backray/ui";
```
