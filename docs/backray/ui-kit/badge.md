# Badge

A short label for a status or a count, in the `primary`, `secondary`, `outline` or `destructive` tone. `badgeVariants` styles a link the same way.

```tsx
import { Badge, badgeVariants } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-badge--docs" target="_blank">open it in Storybook</a> and use the toolbar.
