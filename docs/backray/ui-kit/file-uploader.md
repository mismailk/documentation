# File uploader

A drop zone and file picker that checks the file type, size and count before accepting a file.

```tsx
import { FileUploader } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-fileuploader--docs" target="_blank">open it in Storybook</a> and use the toolbar.
