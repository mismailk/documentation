# File preview

An image, or a card with a file's name, type and size and a link to open it. `FilePreviewDialog` shows it full size.

```tsx
import { FilePreview, FilePreviewDialog } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-filepreview--docs" target="_blank">open it in Storybook</a> and use the toolbar.
