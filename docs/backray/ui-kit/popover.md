# Popover

A small panel opened next to a button, for extra content or a short form.

```tsx
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverHeader,
  PopoverTitle,
  PopoverDescription,
} from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-popover--docs" target="_blank">open it in Storybook</a> and use the toolbar.
