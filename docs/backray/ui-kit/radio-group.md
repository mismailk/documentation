# Radio group

A set of options where only one can be picked.

```tsx
import { RadioGroup, RadioGroupItem } from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-radiogroup--docs" target="_blank">open it in Storybook</a> and use the toolbar.
