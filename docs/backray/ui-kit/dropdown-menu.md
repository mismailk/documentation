# Dropdown menu

A menu of actions opened from a button, with checkbox and radio items, groups and submenus.

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuCheckboxItem,
  DropdownMenuRadioGroup,
  DropdownMenuRadioItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuSub,
} from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-dropdownmenu--docs" target="_blank">open it in Storybook</a> and use the toolbar.
