# Card

A bordered box for a group of content, with a header, title, description, action, content and footer.

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardAction,
  CardContent,
  CardFooter,
} from "@backray/ui";
```

Every example below is live. To switch between light and dark, or left-to-right and right-to-left, <a href="../storybook/index.html?path=/docs/components-card--docs" target="_blank">open it in Storybook</a> and use the toolbar.
